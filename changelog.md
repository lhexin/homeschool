# Changelog

## 2026-09-26

Initial build.

- App shell with two fully separate themed home screens: Charlie (space) and Naomi (unicorn).
- Data-driven subjects, lessons, and badges — see `/data`.
- Subjects covered: reading, maths, science, Mandarin, entrepreneurship (Charlie's book business), piano, Half Moon theatre, ballet, phonics, life skills.
- Badge system: rule-based (auto-awarded from usage) and parent-awarded (for real-world effort like Half Moon or ballet) via the parent dashboard.
- Two example mini-games: times-tables race, phonics letter-sound match (with spoken audio).
- Parent dashboard (long-press the mascot/gear icon): progress bars, badge management.
- PWA manifest + icons for "Add to Home Screen".
